ข้อ 1 ระบบการตรวจลงทะเบียน
    :เป็นการทำงานโดยการจะรับพารามิเตอร์แรกเป็น error เพื่ออันที่ 2 จะเป็นข้อมูลที่ส่งมา หากทำงานสำเร็จจะจะส่งพารามิเตอร์แรกเป็น null เพื่อบอกว่าไม่มีค่า error 
ข้อ 2 แปลงเป็น Promise
    :ครอปโค้ดตัวเดิมไว้ภายใต้ พารามอเตอร์ 2 ตัว คือ resolve/reject จะมีการทำงานเสมอแบบเป็นขั้นตอนไปเรื่อยๆ โดยจะคืนค่าออกมาเป็น Object Promise 
ข้อ 3 รายงานฉบับ Async
    :การใช้งานร่วมกันในแต่ละรอบ โปรแกรมจะรอทำตามลำดับไปเรื่อยๆโดยจะทำแต่ละขั้นตอนให้เสร็จก่อน โดยจะทำงานทีเดียวแล้วได้ผลลัพธ์ทีเดียว ซึ่งใช้เวลาช้า
ข้อ 4 เลือกนักสืบ
    :โดยแต่ละตัวจะมีเงื่อนไขการทำงานคือโดยเลือกการทำงานตามสถานการณ์ที่เรากำหนดขึ้น
